## Acceptance criteria

### US-9 See the source of each answer

1. When the assistant answers an in-scope question, the assistant shall name the document and the article, section, action, measure or glossary entry of each source it used.
2. When the assistant cites an article or section, the assistant shall cite the one that contains the supporting passage.
3. When the assistant cites a document, the assistant shall show a link to its official URL from the document inventory.

### US-10 See the source of each part of an answer

1. When an answer uses more than one source, the assistant shall place each citation next to the part it supports.
