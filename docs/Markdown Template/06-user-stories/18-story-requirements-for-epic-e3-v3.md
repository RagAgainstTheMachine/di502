## Acceptance criteria

### US-9 Ask a follow-up without repeating myself


1. When the user's question contains a reference word that refers to an item in the most recent answer in the same conversation, the assistant shall answer about that item.

## Terms

- **Reference word:** a form of the Turkish pronouns "bu", "şu" or "o" (for example "bunu", "onun").
- **Item:** the action, measure, article, document or term that an answer is about.
