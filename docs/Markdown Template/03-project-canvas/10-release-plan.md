# Release Plan

The project has four sprints and progresses from a reviewed project charter to a team-tested alpha, a cloud-hosted beta for pilot participants, and a release candidate for the final demonstration. The dates and deliverable names below match [Milestones](02-milestones.md) and [Deliverables](05-deliverables.md). User-story assignments remain in the User Story Map and Jira.

## Release stages

| Stage | What this project hands over | Who uses or reviews it |
|---|---|---|
| Pre-alpha | Project Charter v1 before software testing starts | Project Review Committee and project team |
| Alpha | Local web prototype and baseline evaluation results | Project team |
| Beta | Cloud-hosted assistant for pilot use and feedback | 10 pilot participants: the 4 team members and 6 people outside the team |
| Release candidate | Final demonstration build, pilot evaluation and final report | Project Review Committee |

## Release table

| # | Release | Sprint | Start Date | End Date | Key Deliverable(s) |
|---|---|---|---|---|---|
| 1 | Pre-alpha | Sprint 1 | 14/10/2026 | 28/10/2026 | D1 Project Charter v1 |
| 2 | Alpha 0.1 — tested by the project team on a local web page | Sprint 2 | 04/11/2026 | 18/11/2026 | D2 Q&A Generation-Dataset v1; D3 Default-state measurement report; D4 Dataset Report v1; D5 Alpha prototype; D6 Project Charter v2 |
| 3 | Beta 0.5 — given to 10 pilot participants (the 4 team members and 6 people outside the team) | Sprint 3 | 25/11/2026 | 09/12/2026 | D7 MVP evaluation report; D8 Beta release |
| 4 | Release candidate 1.0 — presented to the Project Review Committee at the final demo | Sprint 4 | 16/12/2026 | 30/12/2026 | D9 Pilot evaluation report; D10 Release candidate; D11 Final report |

Pre-alpha is a planning handover, not a software release. The alpha is used by the project team on a local web page; the beta is accessible to the named pilot participants through a browser. Sprint 4 delivers the pilot evaluation report, release candidate and final report as separate deliverables. The Product Owner's go/no-go decisions between alpha and beta and between beta and release candidate are recorded in [Milestones](02-milestones.md), rather than counted as additional releases here.
