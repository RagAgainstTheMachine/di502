# Assumptions & Constraints

This page records what the plan rests on. Assumptions are bets we have not proven yet; each has a basis, a check, an owner and a matching risk in [Risks](11-risks.md). Constraints are fixed limits, grouped by category; the work they create or remove is listed in [Major Activities](04-major-activities.md). Owners and their roles are listed in [Project Organization](08-project-organization.md).

## 2. Constraints

| # | Category | Constraints | Linked activities / risks |
|---|---|---|---|
| C-01 | Data | The corpus consists of exactly the 8 official documents listed in the Background of the [Project Executive Summary](01-project-executive-summary.md) [2–9]. Documents outside the collection, including parliamentary bills, are not indexed. | [Major Activities](04-major-activities.md): out of scope (foreign regulation, institutions' internal rules, earlier strategies); [Risks](11-risks.md) R-03 |
| C-02 | Data | D05 is used only for PDF pages 642–806. D08 contains only the AI-related Tedbir entries, each with its number and responsible institution. | [Major Activities](04-major-activities.md): in scope (extract and clean the selected parts); D4 in [Deliverables](05-deliverables.md); [Risks](11-risks.md) R-08 |
| C-03 | Data | The collection is a fixed snapshot of the documents as downloaded on the collection date. Anything published after that date is not reflected. The collection date is shown to users (Feature 6). | [Major Activities](04-major-activities.md): in scope (record download dates, show the collection date), out of scope (automatic monitoring and updating of sources); [Risks](11-risks.md) R-03; Jira DI502-18 |
| C-04 | Data | Questions, answers and source documents are in Turkish only. | [Risks](11-risks.md) R-08; Jira DI502-12 |
| C-05 | Model | The solution is retrieval-augmented generation (RAG), as set by the Project Review Committee: answers are generated only from passages retrieved from the corpus. | [Major Activities](04-major-activities.md): in scope (indexing, retrieval, a prompt that restricts answers to the retrieved passages); [Risks](11-risks.md) R-08 |
| C-06 | Model | The assistant answers text questions about the content of the corpus, including questions that combine several documents and follow-up questions in the same conversation. It gives no case-specific legal assessments and no predictions about the final AI law; for these and other out-of-scope questions it replies with a fixed notice that refers the user to the Millî Teknoloji ve Yapay Zekâ Genel Müdürlüğü (Directorate General for National Technology and Artificial Intelligence, Ministry of Industry and Technology). | [Project Executive Summary](01-project-executive-summary.md) exclusions; [Major Activities](04-major-activities.md): in scope (fixed-notice rule and out-of-scope test questions), out-of-scope list; [Risks](11-risks.md) R-09; Jira DI502-13, DI502-14 |
| C-07 | Infrastructure | From the Beta release (D8, 09/12/2026) onwards, the assistant is hosted on Google Cloud; the alpha (D5) runs on a local web page. | D8 in [Deliverables](05-deliverables.md); [Risks](11-risks.md) R-06 |
| C-08 | Integration | Users reach the assistant only through a web page in a browser. The page has no user accounts and no field for personal data. | [Major Activities](04-major-activities.md): out of scope (user accounts, mobile app); C-11; [Risks](11-risks.md) R-10 |
| C-09 | People / process | **Budget:** $100 of Google Cloud credits (fixed, per project). | Same statement as in [Project Executive Summary](01-project-executive-summary.md); [Cost & Funding](07-cost-and-funding.md); [Risks](11-risks.md) R-06 |
| C-10 | People / process | **Duration:** 4 sprints. **Timeline:** 14 October 2026 to 30 December 2026. Charter v1 is due on 28/10/2026; the release candidate is shown at the final presentation on 30/12/2026. | [Milestones](02-milestones.md) M1, M11 |
| C-11 | People / process | No personal data of users or pilot participants is stored in any database, log, vector index or evaluation file (Law No. 6698). Pilot participants are recorded only by a pseudonymous ID. Conversation context for follow-up questions is kept only for the open session. | [Major Activities](04-major-activities.md): in scope (mask personal data in questions before logging, pseudonymous participant IDs), out of scope (user accounts, saved conversation history); [Risks](11-risks.md) R-10; Jira DI502-20 |
| C-12 | People / process | Four students: Muhammed Batuhan Tezcan (Product Owner), Elif Yeşim Koçoğlu (Data Scientist), Utku Uçar (Data Engineer) and Deniz Şenkutlu (Data Engineer). No additional recruitment is possible. Each member works at most 15 hours per week on the project. | [Project Organization](08-project-organization.md); [Cost & Funding](07-cost-and-funding.md) (team capacity); [Major Activities](04-major-activities.md): project management (All stages, pull request reviews); A-07; [Risks](11-risks.md) R-07 |
| C-13 | People / process | DI 502 course rules: planning is done in Jira; documentation is kept as Markdown in Git and synced to Confluence; every branch, commit and pull request carries a Jira key; experiment results are logged in Weights & Biases; all parameters live in `config/rag.yaml`; the evaluation set is fixed before any experiment. | [Major Activities](04-major-activities.md): project management (All stages) |
