# Facilities & Resources

| # | Resource | Description | Responsible Person/Team | Status |
|---|---|---|---|---|
| 1 | Team-owned development laptops | Used for coding, document preparation, the local alpha web page and CPU-based tests. No team member has a dedicated GPU workstation, and no laboratory or shared physical workstation is required. | Project team | Available as of 19 Oct 2026; sufficient for Sprint 1 documentation and local development |
| 2 | Google Cloud education credit — $100 fixed project allocation | Funds cloud development, evaluation and browser-accessible deployment from 14 Oct to 30 Dec 2026. Planned use is capped at $70, leaving $30 in reserve; spending is checked at each sprint review and controlled with a billing budget alert. | Elif Yeşim Koçoğlu | Credit available as of 19 Oct 2026; cloud project and billing alert required by 04 Nov 2026 (Dependencies row 4) |
| 3 | Google Cloud project and scheduled GPU compute | Runs the self-hosted language model, embedding model and cloud application when GPU compute is needed. The final machine type and GPU are selected through the architecture spikes according to model memory, regional availability and the budget; an NVIDIA T4 configuration is an initial candidate. Compute is stopped outside scheduled development, evaluation and demonstration periods. | Elif Yeşim Koçoğlu | Planned as of 20 Oct 2026; machine type, GPU quota, region and operating schedule must be confirmed by 04 Nov 2026 |
| 4 | Self-hosted open-source or open-weight language model | Generates Turkish answers only from passages retrieved from the approved corpus, as required by the RAG constraint. A quantized Turkish-capable model is selected after comparing grounded answer quality, refusal behaviour, latency and GPU-memory use. Qwen 3.5 9B served through Ollama is an initial candidate, not a final selection; there is no external LLM API quota. | Deniz Şenkutlu and Elif Yeşim Koçoğlu | Requirements and initial candidate identified as of 20 Oct 2026; final model, quantization and runtime must be selected and reachable from Google Cloud by 04 Nov 2026 |
| 5 | Self-hosted multilingual embedding model | Generates embeddings for the fixed Turkish document collection and user queries without an external embedding API. The final model is selected through a retrieval spike according to Turkish retrieval quality, vector size, latency and compute compatibility. EmbeddingGemma 300M is an initial candidate, not a final selection. | Utku Uçar and Elif Yeşim Koçoğlu | Requirements and initial candidate identified as of 20 Oct 2026; final model and configuration must be selected and reachable from Google Cloud by 04 Nov 2026 |
| 6 | Managed vector database | Stores document-chunk embeddings, chunk text and source metadata and supports similarity search and metadata filtering. Qdrant Cloud and Pinecone are candidates. The project will use only a free or no-additional-cost plan; the selected provider's storage, request and inactivity limits must be recorded before provisioning. No personal data or conversation history is stored in the vector index. | Elif Yeşim Koçoğlu | Candidate services identified as of 20 Oct 2026; provider, plan, limits and API configuration pending the retrieval and architecture spikes |
| 7 | Approved official document collection and source access | Provides the fixed seven-document corpus defined by C-01 through official source URLs. Download date, legal status, permitted page or entry selection and SHA-256 hash are recorded in `data/manifest.csv`; documents are not indexed until the source terms have been checked. Automatic source monitoring and updating are not included. | Utku Uçar | Official sources identified; terms-of-use and licence review required by 28 Oct 2026 (Dependencies row 2), and extraction manifest required by 04 Nov 2026 (Dependencies row 3) |
| 8 | Restricted Google Cloud Storage bucket | Stores the approved raw documents, processed corpus records and manually created vector-index snapshots. Access is limited to project members. It contains no user or pilot-participant personal data and represents the fixed collection snapshot and collection dates required by C-03 and C-11. Usage counts toward the Google Cloud credit. | Utku Uçar and Elif Yeşim Koçoğlu | Planned as of 20 Oct 2026; bucket, retention approach and team permissions must be configured before indexing begins |
| 9 | GitHub repository, Jira and Confluence | Provide version control and pull-request review, backlog and sprint planning, and project documentation. Access is limited to invited team members and reviewers. Every branch, commit and pull request uses a Jira key, and Markdown documentation is synchronized from GitHub to Confluence. The assistant runtime does not depend on these services, and no bulk API use is planned. | Muhammed Batuhan Tezcan and Deniz Şenkutlu | Team access and GitHub–Jira–Confluence connections available as of 19 Oct 2026; process used throughout all four sprints |
| 10 | Weights & Biases experiment workspace | Records the committed `config/rag.yaml` values, model and retrieval identifiers, and baseline and later experiment metrics for the fixed 40-question evaluation set. Use is limited to the available free plan; its current storage and seat limits must be checked when the workspace is created. Source documents, unmasked personal data and complete user conversations are not uploaded. | Elif Yeşim Koçoğlu; experiment records maintained by the project team | Free-plan workspace selected as of 20 Oct 2026; workspace and API access required by 11 Nov 2026 before the baseline run (Dependencies row 5) |
| 11 | Deployment environment for the beta and release candidate | Web application hosted on Google Cloud and accessed through a browser by pilot users. | Elif Yeşim Koçoğlu | External browser access planned for 02 Dec 2026; beta due 09 Dec 2026 and release candidate due 30 Dec 2026 |
